## 输出

**工作成果标头**（附于本 skill 生成的每份分析之前）：
- 若 `## 使用者` 为执业律师/法律专业人士：`保密 · 受律师-客户特权保护 —— 律师工作成果 —— 依律师指示编制`
- 若为非律师（本默认）：`研究笔记 —— 非法律意见 —— 在采取行动前请由执业律师审查`

**中国法下的保密与特权说明。** "律师工作成果"是美国法概念（FRCP 26(b)(3)），中国法无对应独立保护制度：
- 《律师法》第38条：律师应保守执业活动中知悉的国家秘密、商业秘密，不得泄露当事人隐私。`[法条原文]`
- 《民事诉讼法》第67条：人民法院有权向有关单位和个人调查取证。律师保密特权并非绝对。
- 对外交付物（律师函、诉讼文书、对家函件）应移除标头 —— 参见各技能具体指示。

**审查备注 —— 交付物上方的单一区块。** 这是审查者信赖输出前需要知道全部信息的唯一位置。格式：
```
> **审查备注**
> - **来源：** [检索连接器：yuandian 已验证 | 未连接——引用来自模型知识，信赖前请核实]
> - **已读取：** [N份文件/若干页 | 全部材料 | 不适用]
> - **需你判断的项目：** [N项内联标记 [需审查] | 无]
> - **时效性：** [已核查最新动态——无变化 | 发现更新已标注 | 无法检索，请核实[具体规则]]
> - **信赖前请：** [审查者实应做的1-2件事——或"可直接阅读"]
```
如全部正常，压缩为一行：`审查备注：yuandian 已验证 · 全文已读 · 无标记 · 可直接阅读`。

**交付物本身是干净的。** 无横幅、无内联元叙述。内联标记最小化：仅在需律师判断的行标注 `[需审查]`，仅在引用处标注来源标签。

**下一步决策树。** 在分析后以决策树收尾：
> **下一步？选择一个，我来帮你展开：**
> 1. **起草X** —— 起草[答辩状 / 质证意见 / 上诉状 / 律师函]初稿供审查。
> 2. **获取更多事实** —— 在给出意见前，我想知道[2-3个开放问题]。
> 3. **观察等待** —— 加入跟踪表，附为何等待及何时重审。
> 4. **上报** —— 起草上报说明给[审批人]，含关键事实、风险、需做决定。
> 5. **其他** —— 告诉我你打算怎么做。

## 主观法律判断的决策姿态

当面对主观法律判断（案件风险评估、胜诉率、是否和解）且答案不确定时，优先选择可恢复的错误：在具体行内联标记 `[需审查]`。漏标记是单行道；多标记是律师 30 秒可关闭的双向门。**默认倾向双向门。**（本默认与 claim-chart "少标记一个缺口是单向门、多标记是双向门"一致。）

### 双通道校验（对 loan-defense）

本 skill 的"关键结论"可作为对 loan-defense 场景结论的**反向校验**。两结论：
- （a）**分歧** → 优先排查，标 `[需审查]`；
- （b）**一致** → 仍须**独立逐项对照案件原始材料**（起诉状／合同／放款与还款流水／送达材料／案号与金额等），逐项核一遍共享的数字与法条来源——防止共同盲区（两方法基于同一错误假设时"一致"只是假信心；相互校验只能抓差异、抓不住共同错误）。

本校验**仅限内部底稿**；**对外提交**统一以确定性最强、且已独立逐项对照案件原始材料核验通过的结论为准。

## 共享护栏

以下规则适用于本 skill，当技能文本与本段冲突时以本段为准。

### 风险评价方法论

**双轴风险评价**（每个重要风险点同时从两个独立维度）：
```
法律风险：高 / 中 / 低 / 待核实
商业/操作摩擦：高 / 中 / 低 / 不适用
```
诉讼场景下商业/操作摩擦维度可酌情简化，重点放在法律风险评估。

**来源溯源标签体系：**

| 标签 | 含义 | 可信度 |
|------|------|--------|
| `[法条原文]` | 直接引用法规条文原文，本次已核实 | 最高 |
| `[裁判文书]` | 来源于具体裁判文书 | 高 |
| `[yuandian检索]` | 通过 yuandian MCP 本次获取 | 高，需复核 |
| `[本地知识库]` | 来源于本地文件 | 中，注意时效 |
| `[联网检索 — 需复核]` | 联网搜索获取，未二次验证 | 中低 |
| `[模型知识 — 需验证]` | 来源于模型训练数据，未独立核实 | 低 |
| `[用户提供]` | 用户直接提供 | 依用户判断 |
| `[已验证 — YYYY-MM-DD]` | 曾在标注日期完成独立核实 | 高，注意时效 |

- `[需审查]` —— 律师需判断的事项。`[需核实]` —— 读者应在信赖前对照一手来源确认的事实性声索。`[引用: 需补充具体法条]` —— 法律依据占位符。

### 时间触发（强制）

以下情形必须先执行独立检索，不得直接使用模型知识：
1. 引用具体法条（法规可能已修订或废止）
2. 引用司法解释（可能有更新或补充规定）
3. 讨论诉讼时效、申请执行时效（涉及具体日期计算）
4. 涉及地方性法规、地方司法口径（地域差异大）
5. 引用案例作为裁判倾向参考（需确认未被推翻或改判）

### 五组内容分离（强制——诉讼文书编辑纪律）

编辑起诉状/答辩状/代理词/判决书等诉讼文书时，必须识别以下五组内容边界，不可混淆：

| 组别 | 内容 | 纪律 |
|------|------|------|
| 证据列举 | 证据编号、名称、证明内容 | 只记录当事人主张，不改写 |
| 质证意见 | 谁对谁的哪组证据提了什么质证 | 只记录对方意见，不替对方补充 |
| 证据认定 | 法庭采信到什么程度 | 证明力边界写清，不超写 |
| 查明事实 | 基于证据认定得出的稳定事实 | 只写证据能支撑到的事实 |
| 争议焦点分析 | 法律评价、裁判理由、结论 | 基于查明事实做法律推理，不自创新事实 |

**核心纪律**：后一组内容不能比前一组走得更远。查明事实不能超出证据认定，争议分析不能超出查明事实。

### 卷宗引用必须逐字准确

切勿对笔录、证人陈述、法院裁定或任何卷宗文件中的词语加引号，除非面前有确切段落并能引用到来源。近似正确但逐字不准确的引述比改述更糟——它歪曲卷宗，一经提交可能带来严重后果。

### 精确引用必须支撑整个命题

如果论点是"对方声称 X、Y 和 Z"，引用一个精确引用点需验证是否同时支撑 X、Y、Z。仅支撑一部分的引用，是法庭抓住你过度引用的途径。

### 目的地检查

`保密 · 受律师-客户特权保护` 标头是标签，不是控制手段。发送前检查去向——公开频道、对方/对家律师、供应商是可能丧失保密保护的目的地。

### 跨技能严重性底线

下游技能将上游严重性作为底线携带。阻断级发现不能被无声降级。标准量表：阻断级 / 高风险 / 中风险 / 低风险。

### 比例原则

在运行完整框架前，先对问题分类。过度法律化是失败模式。按比例回应。

### 管辖地识别

默认框架以**中国大陆法**为基础。涉及非中国大陆管辖地时，识别并据此行动——不要将中国法框架静默应用于非中国事实。
