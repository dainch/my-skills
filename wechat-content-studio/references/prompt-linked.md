## 模板 3：图文 + 视频联动

```text
按“公众号 + 视频号联动全程代做流程”处理这批素材。

任务类型：同一份素材同时做文章 + 视频
运行模式：[direct / continuous / outline_first；默认 direct]
主题：[这次要讲什么]
目标受众：[同行 / 甲方 / 学生 / 公众 / 混合]
发布目标：[涨粉 / 建立专业形象 / 获客 / 项目展示 / 知识科普 / 课程推广]
账号定位：[希望账号长期被记住成什么样]
素材路径：[填写本地文件路径；如果没有路径，就写“素材稍后上传”]
素材类型：[录音 / 视频 / 报告 / PPT / 笔记 / 图片 / 图纸 / 评估报告 / 监测数据 / 混合]
项目类型：[轨道交通 / 市政道路 / 桥隧 / 深基坑 / 高边坡 / 综合管廊 / 涉铁安评 / 地铁保护区 / 监测调查 / 其他]

专业要求：
- 核心观点：[最想统一传达的核心观点]
- 专业依据：[规范条文 / 标准编号 / 设计资料 / 施工记录 / 监测数据 / 论文报告]
- 适用边界：[适用于哪些情况；不要泛化到哪些情况]
- 禁区：[不能公开的信息、不能写的项目名称、不能碰的敏感点]
- 公开边界：[可公开 / 需脱敏 / 仅内部参考 / 不确定先提醒]

增长要求：
- 是否允许自动选题：[否 / 是；选择是时主题可写“由你选择”]
- 是否自动搜索同题公众号及权威来源：[默认是 / 否]
- 网络候选用途：[默认仅用于需求、结构和案例线索 / 经确认后可作证据]
- 工程关键词：[运营安全保护区 / 影响性安全评估 / 盾构区间 / 明挖基坑 / 深基坑 / 高边坡 / 综合管廊 / 下穿通道 / 空间预留]
- 主关键词：[核心搜索词]
- 长尾关键词：[读者/观众可能搜索的问题]
- 标题方向：[专业关键词型 / 痛点型 / 误区纠偏型 / 案例复盘型 / 清单工具型 / 都要]
- 希望关联的已发布主题：[文章标题、视频标题或主题，若没有就写“暂无”]
- 将要发布的相关内容：[下一篇、下一条视频、系列计划，若没有就写“由你建议”]
- 是否需要系列化规划：[是 / 否]

图文要求：
- 希望出现的图表：[概念图 / 流程图 / 剖面图 / 对比表 / 检查清单 / 监测曲线 / 现场照片说明]
- 是否需要封面文案：[是 / 否]
- 是否需要图表清单：[是 / 否]

文章要求：
- 字数：[如 1500-2000 字]
- 标题备选数量：[如 8 个]
- 是否需要摘要：[是 / 否]
- 是否需要 FAQ 搜索问答：[是 / 否]

视频要求：
- 条数：[如 1 条 / 2 条 / 3 条]
- 时长：[如 每条 30-60 秒]
- 是否需要字幕稿：[是 / 否]
- 是否需要旁白稿：[是 / 否]
- 是否需要配音：[是 / 否]
- 是否需要封面标题：[是 / 否]
- 是否需要话题词：[是 / 否]
- 是否需要评论区置顶文案：[默认否 / 是]
- 是否允许任何导流元素（二维码 / 联系方式 / 外链 / 回复领取 / 私信领取 / 跳转提示）：[默认否 / 是]
- 是否需要成片：[是 / 否]

合规要求：
- 是否需要来源标注建议：[是 / 否]
- 是否需要原创/AI 辅助声明建议：[是 / 否]
- 是否需要敏感信息脱敏检查：[是 / 否]

交付要求：
- 截止时间：[如 本周五晚 8 点前]
- 是否先给提纲/脚本骨架审一遍：[是 / 否]
- 停止位置：[默认 ready / outline / reviewing]

补充说明：
[其他要求]
```

## 一个真实示例

```text
按“公众号 + 视频号联动全程代做流程”处理这批素材。

任务类型：同一份素材同时做文章 + 视频
主题：隧道初期支护常见误区
目标受众：岩土与隧道同行
发布目标：建立专业形象
账号定位：用工程案例把复杂岩土问题讲清楚
素材路径：D:\Documents\Codex\materials\隧道初期支护误区讲座.pptx
素材类型：PPT

专业要求：
- 核心观点：初支不是越强越安全，关键是与围岩共同作用
- 专业依据：PPT 中的现场照片、监测曲线、支护参数说明
- 适用边界：重点讨论一般钻爆法山岭隧道，不泛化到所有地下工程
- 禁区：不要出现具体项目名称、监测原始数据和参建单位名称

增长要求：
- 工程关键词：[运营安全保护区 / 影响性安全评估 / 盾构区间 / 明挖基坑 / 深基坑 / 高边坡 / 综合管廊 / 下穿通道 / 空间预留]
- 主关键词：隧道初期支护
- 长尾关键词：初期支护变形过大怎么办、钢拱架间距怎么判断、围岩收敛监测怎么看
- 标题方向：误区纠偏型、案例复盘型、清单工具型都要
- 希望关联的已发布内容：暂无
- 将要发布的相关内容：由你建议
- 是否需要系列化规划：是

图文要求：
- 希望出现的图表：剖面图、对比表、检查清单、监测曲线
- 是否需要封面文案：是
- 是否需要图表清单：是

文章要求：
- 字数：1800 字左右
- 标题备选数量：8 个
- 是否需要摘要：是
- 是否需要 FAQ 搜索问答：是

视频要求：
- 条数：2 条
- 时长：每条 45-60 秒
- 是否需要字幕稿：是
- 是否需要旁白稿：是
- 是否需要配音：否
- 是否需要封面标题：是
- 是否需要话题词：是
- 是否需要评论区置顶文案：否
- 是否允许任何导流元素（二维码 / 联系方式 / 外链 / 回复领取 / 私信领取 / 跳转提示）：否
- 是否需要成片：否

合规要求：
- 是否需要来源标注建议：是
- 是否需要原创/AI 辅助声明建议：是
- 是否需要敏感信息脱敏检查：是

交付要求：
- 截止时间：明晚 8 点前
- 是否先给提纲/脚本骨架审一遍：是

补充说明：
内容尽量少讲教科书定义，多讲现场误区和判断方法。
```
