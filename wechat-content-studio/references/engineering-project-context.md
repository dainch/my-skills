# 工程项目画像

> 本画像来自公司画册与项目目录的只读梳理，用于微信内容选题、表达风格和敏感信息判断；不得把本文件当作可公开披露的完整业绩清单。涉及具体资质、奖项、数量、合作单位、项目状态时，发布前必须回到原始材料复核。

## 1. 公司与能力定位

- 核心定位：以桥隧、轨道交通、市政道路、岩土工程和工程咨询评估为特色的工程技术团队。
- 常见能力：工程设计、工程咨询、安全评估、科研课题、施工疑难问题技术分析、BIM/数字化相关技术应用。
- 业务覆盖：城市轨道交通、市政工程、公路工程、铁路工程、民用建筑、岩土工程、BIM 工程、科研评估。

## 2. 典型项目类型

优先把素材归入以下项目类型之一：

- 轨道交通：地铁车站、区间隧道、高架桥、车辆段、综合交通枢纽、出入段线、换乘站。
- 市政与公路：城市道路、快速路、下穿通道、穿山隧道、桥梁、交通疏解、管线迁改。
- 铁路与城际：高铁/城际隧道、盾构区间、下穿既有铁路或桥桩托换。
- 岩土与地下工程：深基坑、高边坡、软基处理、地基处理、挡墙、滑坡治理。
- 地铁保护与涉铁评估：运营安全保护区、规划控制区、既有线/在建线/规划线影响评估、空间预留专题研究。
- 综合管廊与市政管线：综合管廊、污水管、再生水管、箱涵、顶管、盾构穿越或邻近既有结构。
- 监测与调查：房屋调查、自动化监测、施工影响监测、结构安全性分析。

## 3. 常见专业关键词

- 轨道交通：车站主体、附属结构、围护结构、盾构区间、矿山法隧道、明挖顺作、盖挖顺作、车辆段、综合枢纽。
- 桥隧：大断面隧道、下穿通道、海底隧道、桥梁结构、跨航道桥、隧道病害治理。
- 岩土：深基坑、高边坡、软基处理、地基处理、基坑支护、桩基托换、滑坡治理。
- 安评：安全评估、风险评估、影响性安全评估、数值分析、三维有限元、施工影响、运营安全保护区、空间预留。
- 市政：道路工程、交通疏解、综合管廊、排水、污水管、再生水管、箱涵、顶管。

## 4. 内容选题优先级

优先选择能同时体现专业价值和读者实用价值的角度：

1. 运营地铁/铁路保护区内工程为什么不能只看平面距离。
2. 下穿、上跨、邻近既有结构时，风险评估到底评什么。
3. 深基坑、高边坡、隧道和管廊项目中，哪些判断最容易被忽略。
4. 市政道路、管线、综合管廊与轨道交通交叉时，如何做空间预留和施工影响控制。
5. 设计、咨询、监测、施工资料如何共同支撑一个安全评估结论。
6. 从典型工程案例提炼可复用的检查清单、判断流程和误区纠偏。

## 5. 默认受众

- 工程项目管理人员、设计院工程师、施工单位技术负责人、甲方技术管理人员。
- 轨道交通、市政道路、桥隧、岩土、监测、安全评估相关从业者。
- 需要理解工程风险和审批逻辑的非专业管理者。

## 6. 表达边界

- 可以讲方法、判断逻辑、风险链条、资料清单和常见误区。
- 谨慎公开具体项目名称、线路区间、坐标、净距、结构标高、监测原始数据、未公开图纸和合同报价。
- 对外表达业绩数量、合作单位、奖项、专利、论文时，必须以已公开画册或用户确认材料为准，不凭记忆扩写。
- 对正在进行、投标报价、审查意见、未盖章报告、内部方案比选等内容，默认不公开。
