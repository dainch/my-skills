# 推荐运营规范与不良信息收口

适用对象：所有面向微信公众号 / 视频号公开发布的文章、脚本、标题、封面标题、摘要、导语、结尾文案、评论区文案、公众号消息文案。

优先依据：
- 《网络信息内容生态治理规定》：2020-03-01 起施行。
- 《关于加强“自媒体”管理的通知》：2023-07-10 发布。

## 1. 一票否决项

出现以下任一情况，必须停止并改稿；改不掉就明确说明不能按当前写法发布：

- 发布不完整内容，再通过二维码、文字、链接、图标等把用户引到其他内容、小程序、公众号/服务号、视频号、第三方网页或 App。
- 在正文、摘要、评论区、公众号消息中嵌入外部链接、二维码、回复关键词、私信领取、加微信领取、跳转小程序等离页导流信息。
- 通过多重跳转、定向引流、先关注再获取、先私信再领取等方式，最终引导用户去站外或线下交易。
- 标题夸张、正文不支撑，或标题与正文核心判断明显不一致。
- 把旧闻、旧案例、旧政策包装成“刚发生”“最新”“突发”。
- 断章取义、拼凑截图、拼接语句、用演绎内容冒充真实现场。
- 蹭炒社会热点、消费灾难事故、放大伤亡/冲突/焦虑来换点击。
- 用“立即关注否则错过”“先点关注防失联”“结尾有惊喜”这类方式诱导关注或故留悬念。
- 仿冒官方口吻、冒充监管提醒、伪装成通知/红头文件/内部消息。
- 未核实就写确定性医疗、金融、法律、政策建议。

## 2. 标题与封面标题禁写模式

- 禁用夸大词：如“彻底”“唯一”“必看”“马上封号”“一夜暴涨”“100%”“所有人都要看”。
- 禁用惊悚词：如“吓出冷汗”“太可怕了”“全网炸了”，除非正文是对情绪化说法的拆解且标题已降温。
- 禁用误导时效：正文不是当天新信息，就不用“最新”“突发”“刚刚”“紧急提醒”。
- 禁用热点借壳：正文主线是专业知识，就不要硬套社会热点壳子引流。
- 标题优先写成：`关键词 + 场景/问题 + 结论边界`。

## 3. 正文与摘要收口规则

- 涉及时事、公共政策、社会事件、事故灾害时，必须写明信息来源与时间；旧闻复盘要显式写“某年某月案例”。
- 不写未经证实的伤亡、处罚、封号、收益、政策走向、行业规模、官方态度。
- 不把个案、截图、聊天记录、单次项目经验写成通用结论。
- 不渲染群体对立、地域对立、职业对立，也不做羞辱式表达。
- 不展示血腥、惊悚、性暗示、未成年人可模仿的危险步骤。
- 使用 AI 生成图片、演绎画面、示意图时，如可能被误认成真实现场，应显式标注“示意/演绎/AI 生成”。
- 不写“扫码领取完整版”“回复关键词获取模板”“加微信看全文”“点击链接查看完整版”“移步视频号/公众号/小程序”等导流句。
- 结尾默认只做站内收束，不放外链、二维码、交易引导、私信引导。
- “欢迎投稿与交流”可作为中性栏目标题保留；其下固定展示“投稿邮箱”“小编微信”不视为发布门禁问题。仍不得写“扫码领取”“回复领取”“私信领取”“加微信看全文”等导流动作。

## 4. 评论区与消息区收口规则

- 默认不生成评论区置顶导流文案；只有用户明确要求时，才生成不含跳转、不含联系方式、不含二维码的弱互动版本。
- 公众号消息、自动回复、群发配文若会引导离开当前页面，同样视为导流风险，不因“不是正文”而豁免。
- 不使用“评论区留 1”“私信我发你”“后台回复领取”“点击名片进入”等半显性导流写法。

## 5. 高频改稿动作

- 把“震惊式标题”改成“问题式 / 误区纠偏式 / 清单式标题”。
- 把“最新提醒”改成“适用边界 + 当前已知口径”。
- 把“灾难事故细节渲染”改成“风险链条、管理启示、预防清单”。
- 把“你不看就亏 / 不关注会失联”改成“如果你也在做这类项目，可收藏备用”。
- 把“绝对化结论”改成“在什么条件下更常见 / 不适用于哪些情况”。
- 把“扫码/私信/回复/点击链接领取”改成“直接在文内给完整信息”。
- 把“文章导视频、视频导文章”改成“同主题后续选题建议”，不写成公开 CTA。

## 6. 发布前快速自查

- 标题是否存在夸张、惊悚、假时效、仿官方、故留悬念。
- 摘要和首屏是否把旧闻说成新事，或把猜测写成事实。
- 正文是否在消费事故、蹭炒热点，还是在提供判断框架和可执行信息。
- 任何一张图、任何一句引用，是否可能被误读为真实现场或官方口径。
- 正文、结尾、评论区、消息区是否出现二维码、外链、回复领取、私信领取、加微信领取或跨页跳转提示；固定投稿邮箱和小编微信除外。
- 内容是否已经完整到不需要“去别处看完整版”。
