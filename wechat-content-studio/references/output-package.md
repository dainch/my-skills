# 标准交付包

## 1. 公众号文章包

默认落地到 `600-Output/01-WeChat/`：

- `主题-YYMMDD.md`：公众号成稿，包含合规 frontmatter。
- `Attachments/主题-公众号封面-YYMMDD.png`：主封面，默认 `2350 × 1000`。
- `主题-发布清单-YYMMDD.json`：正文、封面、来源、校审结果与禁用状态的发布接口清单。
- 如有必要，在正文中直接放入可发布表格、清单和图片占位；不要另建无长期价值的辅助资产文件。

## 2. 视频号视频包

当用户需要脚本或成片时，围绕同一主题组织：

- `主题-视频脚本-YYMMDD.md`：标题、钩子、口播、字幕、发布文案；如用户明确要求，再附置顶评论。
- `renders/主题-视频-YYMMDD.mp4`：如已生成成片。
- `renders/主题-视频封面-YYMMDD.png`：如已生成视频封面。

## 3. 图文联动包

联动任务默认至少包含：

- 公众号成稿。
- 公众号主封面。
- 1 到 3 条视频脚本。
- 同主题系列规划说明（不默认写成公开导流语句）。
- 后续 1 到 2 个系列选题建议。

## 4. 命名与复核

- 文件名避免空格，日期使用 `YYMMDD`。
- 同一主题的文章、封面、脚本、成片要能从文件名识别关联关系。
- 完成声明必须列出核心交付物路径，封面还要列出尺寸和比例。
- 正文必须通过 `scripts/validate_wechat_article.py`；发布清单使用 `schema_version: 2`，并为专业数字或行动阈值填写 `claim_evidence`。
- 发布清单必须通过 `scripts/validate_publish_manifest.py`；只有实际发布后才能把文章 `status` 改为 `published`。
