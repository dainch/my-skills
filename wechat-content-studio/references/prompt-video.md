# 投喂模板使用规则

把方括号内容替换为本次任务信息；有本地素材就填路径，没有就说明“素材稍后上传”。已发布内容与后续计划只用于内部判断主题延续性，不默认写成公开导流文案。

## 模板 2：视频号视频

```text
按“视频号全程代做流程”处理这批素材。

任务类型：视频号视频
运行模式：[direct / continuous / outline_first；默认 direct]
主题：[这次要讲什么]
目标受众：[同行 / 甲方 / 学生 / 公众 / 混合]
发布目标：[涨粉 / 建立专业形象 / 获客 / 项目展示 / 知识科普 / 课程推广]
账号定位：[希望账号长期被记住成什么样]
素材路径：[填写本地文件路径；如果没有路径，就写“素材稍后上传”]
素材类型：[录音 / 视频 / 报告 / PPT / 笔记 / 图片 / 图纸 / 评估报告 / 监测数据 / 混合]
项目类型：[轨道交通 / 市政道路 / 桥隧 / 深基坑 / 高边坡 / 综合管廊 / 涉铁安评 / 地铁保护区 / 监测调查 / 其他]

专业要求：
- 核心观点：[最想让观众记住的 1 句话]
- 专业依据：[规范条文 / 标准编号 / 设计资料 / 施工记录 / 监测数据 / 论文报告]
- 术语读法或解释：[需要特别处理的专业术语]
- 禁区：[不能公开的信息、不能写的项目名称、不能碰的敏感点]
- 公开边界：[可公开 / 需脱敏 / 仅内部参考 / 不确定先提醒]

增长要求：
- 是否允许自动选题：[否 / 是；选择是时主题可写“由你选择”]
- 是否自动搜索同题公众号及权威来源：[默认是 / 否]
- 工程关键词：[运营安全保护区 / 影响性安全评估 / 盾构区间 / 明挖基坑 / 深基坑 / 高边坡 / 综合管廊 / 下穿通道 / 空间预留]
- 主关键词：[如 隧道塌方风险 / 初支变形 / 地表沉降]
- 长尾关键词：[观众可能会搜索的问题]
- 前 3 秒钩子偏好：[反常识 / 现场痛点 / 风险提醒 / 案例开场 / 由你判断]
- 话题词方向：[专业词 / 场景词 / 受众词 / 项目管理词]
- 希望关联的同主题文章：[标题或主题，若没有就写“暂无”]
- 将要发布的相关内容：[下一条视频、系列计划，若没有就写“由你建议”]

视频要求：
- 时长：[如 30 秒 / 60 秒 / 90 秒]
- 出镜方式：[口播 / 旁白 / 图文视频 / 由你判断]
- 是否需要字幕稿：[是 / 否]
- 是否需要旁白稿：[是 / 否]
- 是否需要配音：[是 / 否]
- 是否需要封面标题：[是 / 否]
- 是否需要发布文案：[是 / 否]
- 是否需要评论区置顶文案：[默认否 / 是]
- 是否允许任何导流元素（二维码 / 联系方式 / 外链 / 回复领取 / 私信领取 / 跳转提示）：[默认否 / 是]
- 是否需要成片：[是 / 否]

交付要求：
- 截止时间：[如 明晚 8 点前]
- 是否先给脚本审一遍：[是 / 否]
- 停止位置：[默认 ready / outline / reviewing]

补充说明：
[其他要求]
```
