# 投喂模板使用规则

把方括号内容替换为本次任务信息；有本地素材就填路径，没有就说明“素材稍后上传”。已发布内容与后续计划会影响互链和系列化建议。

## 模板 1：公众号文章

```text
按“公众号全程代做流程”处理这批素材。

任务类型：公众号文章
运行模式：[direct / continuous / outline_first；默认 direct]
主题：[这次要讲什么]
目标受众：[同行 / 甲方 / 学生 / 公众 / 混合]
发布目标：[涨粉 / 建立专业形象 / 获客 / 项目展示 / 知识科普 / 课程推广]
账号定位：[希望账号长期被记住成什么样]
素材路径：[填写本地文件路径；如果没有路径，就写“素材稍后上传”]
素材类型：[录音 / 视频 / 报告 / PPT / 笔记 / 图片 / 图纸 / 评估报告 / 监测数据 / 混合]
项目类型：[轨道交通 / 市政道路 / 桥隧 / 深基坑 / 高边坡 / 综合管廊 / 涉铁安评 / 地铁保护区 / 监测调查 / 其他]

专业要求：
- 核心观点：[最想让读者记住的 1-3 句话]
- 专业依据：[规范条文 / 标准编号 / 设计资料 / 施工记录 / 监测数据 / 论文报告]
- 适用边界：[适用于哪些工程条件；不适用于哪些情况]
- 高风险领域：[无 / 时事 / 公共政策 / 社会事件 / 灾害事故 / 医疗 / 金融 / 法律 / 未成年人]
- 信息来源与时间：[如涉及政策、事故、新闻、案例复盘，请写来源与日期]
- 禁区：[不能公开的信息、不能写的项目名称、不能碰的敏感点]
- 公开边界：[可公开 / 需脱敏 / 仅内部参考 / 不确定先提醒]

增长要求：
- 是否允许自动选题：[否 / 是；选择是时主题可写“由你选择”]
- 是否自动搜索同题公众号及权威来源：[默认是 / 否]
- 网络候选用途：[默认仅用于需求、结构和案例线索 / 经确认后可作证据]
- 工程关键词：[运营安全保护区 / 影响性安全评估 / 盾构区间 / 明挖基坑 / 深基坑 / 高边坡 / 综合管廊 / 下穿通道 / 空间预留]
- 主关键词：[如 隧道初期支护 / 围岩变形 / 超前地质预报]
- 长尾关键词：[如 初期支护变形过大怎么办 / 围岩收敛监测怎么看]
- 标题方向：[专业关键词型 / 痛点型 / 误区纠偏型 / 案例复盘型 / 清单工具型 / 都要]
- 是否允许借热点切入：[否 / 可轻度借势但不能蹭炒 / 是]
- **关键词库**：自动检索 [[Term-SEO-词汇表-250625|SEO 关键词库]] 中与主题匹配的词条，优先取痛点 5 分或微信指数已验证的选题，直接复用"适用标题"句式
- 希望关联的已发布主题：[文章标题、视频标题或主题，若没有就写“暂无”]
- 将要发布的相关内容：[下一篇、下一条视频、系列计划，若没有就写“由你建议”]

图文要求：
- 是否需要封面文案：[是 / 否]
- 是否需要配图建议：[是 / 否]
- 是否需要我设计图表清单：[是 / 否]
- 希望出现的图表：[概念图 / 流程图 / 剖面图 / 对比表 / 检查清单 / 监测曲线 / 现场照片说明]

文章要求：
- 写作方式：[默认叙事化展开（现场冲突开场）/ 纯技术手册体 / 纯清单体]
- 开篇场景是否可虚构复合：[默认可复合但数值须标注量级示例 / 必须真实案例]
- 是否需要有争议双方的对立呈现：[默认是 / 否]
- 字数：[如 1500-2000 字]
- 标题备选数量：[如 8 个]
- 是否需要摘要：[是 / 否]
- 是否需要 FAQ 搜索问答：[是 / 否]
- 是否需要文末互动引导：[是 / 否]
- 是否允许任何导流元素（二维码 / 联系方式 / 外链 / 回复领取 / 私信领取 / 跳转提示）：[默认否 / 是]

交付要求：
- 截止时间：[如 明晚 8 点前]
- 是否先给提纲审一遍：[是 / 否]
- 停止位置：[默认 ready / outline / reviewing]

补充说明：
[其他要求]
```
