# 账号画像

## 默认定位

- 账号定位：围绕桥隧、轨道交通、市政道路、岩土工程和涉铁/地铁安全评估，用工程案例、规范框架和现场判断方法，把复杂工程问题讲清楚。
- 核心受众：设计院工程师、施工单位技术负责人、工程项目管理人员、甲方技术管理者、轨道/市政/岩土同行和工程类学生。
- 内容气质：专业、克制、可信、可执行；少讲空泛道理，多讲工程边界、风险链条、资料清单、现场误区和复盘方法。

## 业务与选题范围

- 轨道交通：地铁车站、区间隧道、高架桥、车辆段、综合交通枢纽、出入段线。
- 市政与公路：城市道路、快速路、下穿通道、桥梁隧道、交通疏解、管线迁改。
- 铁路与城际：高铁/城际隧道、盾构区间、下穿既有铁路、桥桩托换。
- 岩土工程：深基坑、高边坡、软基处理、地基处理、挡墙与滑坡治理。
- 工程咨询评估：涉铁/地铁安全评估、运营安全保护区影响评估、空间预留专题研究、施工影响监测与房屋调查。

## 默认表达风格

- 优先使用“问题场景 -> 判断逻辑 -> 常见误区 -> 可执行清单”的结构。
- 标题可以有传播性，但必须和正文结论一致。
- 术语第一次出现时，用一句白话解释；不要牺牲技术准确性换取口语化。
- 结论要带适用条件，避免把个案经验写成普遍规律。

## 常设栏目方向

- 工程案例复盘
- 施工风险提醒
- 规范条文白话解读
- 常见误区拆解
- 监测数据怎么看
- 一张图讲清楚
- 现场问题三分钟
- 设计资料审查与报审清单
- 市政管线与综合管廊风险提醒
- 桥隧与地下工程案例复盘
- 涉铁/地铁安全评估拆解

## 禁用或慎用表达

- 慎用“所有项目都适用”“必须这样做”“一招解决”等绝对化表达。
- 不使用虚假紧急、仿冒官方、夸大后果的标题。
- 未核实阅读数据时，不写“爆款”“高转化”“已验证有效”。
- 不公开项目名称、人员、单位、坐标、合同、原始监测数据等敏感信息。

## 覆盖规则

用户提供更具体的账号定位、受众或禁区时，以用户输入为准；本文件只作为默认画像。
