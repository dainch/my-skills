# 交付清单

## 1. 公众号文章默认交付

当用户要公众号文章，默认按以下顺序输出：

1. 标题备选 6-10 个
2. 主关键词 + 长尾关键词 + 同义词
3. 公众号主封面图片（默认一并生成，2.35:1）+ 封面文案或封面方向
4. 摘要
5. 正文成稿
6. FAQ 搜索问答
7. 文末互动引导
8. 可自然放入正文的图片/表格建议
9. 同主题后续选题建议（如需系列化）
10. 来源账本摘要 + 六项校审结果 + 发布清单

### 文章质量门槛

- **按叙事化标准写作**：开篇 3 段内进入具体场景（角色 + 数字 + 代价），争议类选题须呈现双方合理性，故事之后有明确转场锚回推导。详见 `editorial-rules.md` 第 0 节。
- 开头 3 段内进入问题
- 首屏出现核心关键词和核心判断
- 小标题适合手机阅读
- 每一段都服务于读者理解，不保留内部解释性废话
- 不把图表清单、配图说明、工作备注直接留在正文
- 技术数值可追溯，或明确标注「量级示例 / 仅示意 / 须代入计算」
- 引用块金句控制在 3~6 处，且只写正文已论证的判断
- 微信公众号主封面默认按 **2.35:1** 比例生成成品图片；如果同时做方封或跨平台封面，需显式标注为额外规格。未验证尺寸前，不得声明封面已完成。默认优先用 `scripts/create_wechat_cover.py` 生成主封面
- **封面主标题控制在 6~7 个汉字内**，超出会强制折行；生成后必须查看成图确认未折行

## 2. 视频号视频默认交付

当用户要视频号视频，默认按以下顺序输出：

1. 标题备选
2. 封面标题
3. 前 3 秒钩子
4. 30-60 秒主版本脚本
5. 逐句字幕稿
6. 发布文案
7. 评论区置顶文案（仅用户明确要求时）
8. 同主题后续选题建议（仅作内部策划参考）

### 视频质量门槛

- 前 3 秒必须有问题、反常识、风险提醒或现场痛点
- 前 5 秒说出核心关键词
- 一条视频只讲一个核心判断
- 字幕保留关键词，不能全是口水话
- 口播、封面、标题保持同一口径

## 3. 图文联动默认交付

当用户要“文章 + 视频”联动，默认交付：

1. 文章标题矩阵
2. 文章摘要 + 正文成稿
3. 1-3 条视频脚本
4. 每条视频的封面标题与字幕稿
5. 同主题后续 1-2 个选题建议
6. 文章与视频的主题协同说明（不默认写成公开导流语句）

### 联动结构建议

- 文章负责完整展开：背景、边界、对比、误区、方法
- 视频负责快速抓人：钩子、判断、例子、结论
- 同一关键词可在文章、视频标题、字幕中重复出现，但不要为了导流额外塞置顶评论、跳转提示或领取口令

## 4. 用户明确要求先看骨架时

只有在用户明确要求“先看提纲/脚本骨架”时，才先交付：

- 标题方向
- 关键词表
- 提纲
- 镜头或脚本结构

否则默认直接给更接近成稿的版本。

## 5. 连续生产交付

用户要求自动选题或连续完成时，额外交付：

1. 候选选题评分与最终选择依据
2. 公众号及权威来源候选清单，未确认条目保持 `candidate`
3. `draft -> reviewing -> ready` 状态记录
4. 六项自动校审结果
5. `主题-发布清单-YYMMDD.json`

最终发布不属于默认交付；不得把“发布包已就绪”表述为“已发布”。
