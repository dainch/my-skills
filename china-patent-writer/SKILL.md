## 二、发明专利五大核心组成

### 1. 权利要求书 (Claims)

**核心作用**：划定法律保护范围，侵权判断的唯一依据

**核心结构**：1 个独立权利要求 + N 个从属权利要求

**独立权利要求模板**：
```
一种 [发明名称]，包括 [基础部件 A]、[基础部件 B]；
其特征在于，还包括 [创新部件 C]、[创新部件 D]、[创新部件 E]；
所述 [C] 设置于 [A] 的 [位置]，且所述 [C] 与 [B] 固定连接；
所述 [D] 设置于 [A] 的 [位置]，且所述 [D] 的 [部分] 与 [C] 相连通；
所述 [E] 设置于 [C] 下方的 [A] 上。
```

**从属权利要求分层防御**：
- 第一层（权利要求 2-4）：限定核心总成的具体结构
- 第二层（权利要求 5-6）：补充核心总成的优化特征
- 第三层（权利要求 7-10）：细化辅助模块

**撰写技巧**：
- 采用功能性表述（"驱动总成"而非"转轴 + 电机"）
- 避免多余限定（材质、规格等放入从属权利要求）
- 反向排除法验证必要特征

### 2. 说明书 (Description)

**核心原则**：以公开换保护

**五大模块**：
```
## 技术领域          → 精准定调，不宽不窄
## 背景技术          → 场景铺垫→问题总结→对比现有方案
## 发明内容          → 技术问题→技术方案→有益效果
## 附图说明          → 规范描述每幅图的展示内容
## 具体实施方式      → 补充材料、参数、工作流程
```

**三删一增扩写权利要求书**：
- 三删：删"其特征在于"、删括号内编号、删前面序号
- 一增：从属权利要求段首加"本发明进一步设置为"

### 3. 说明书附图

**要求**：
- 黑色线条、白色背景，无彩色、阴影
- 阿拉伯数字编号（1、2、3...），全文统一
- 无需标尺寸、公差、材质

### 4. 说明书摘要

**字数**：不超过 300 字
**四要素**：专利名称、技术领域、技术方案要点、有益效果

### 5. 摘要附图

**选择**：最能体现核心创新的一幅附图

## 三、专利撰写全流程

### 阶段 1：创新点挖掘
```
场景拆解 → 痛点分类 → 核心聚焦 → 方案落地
```

**痛点分类维度**：
- 效率痛点（处理速度慢、耗时长）
- 操作痛点（操作复杂、需专业人员）
- 可靠性痛点（易损坏、维护频繁）
- 成本痛点（成本高、资源浪费）

### 阶段 2：技术情报检索
**四大检索平台**：
| 平台类型 | 代表平台 | 核心作用 |
|---------|---------|---------|
| 专利数据平台 | 国家知识产权局、专利汇、WIPO | 查现有方案 |
| 论文数据平台 | 知网、万方、Web of Science | 挖理论依据 |
| 开放式文档平台 | 百度百科、百度文库 | 拓技术视野 |
| 网络视频资源 | B 站、抖音 | 直观理解结构 |

### 阶段 3：权利要求书撰写
**独立权利要求撰写三步法**：
1. 明确核心技术问题
2. 提炼必要技术特征（不可缺少性 + 区别性）
3. 按固定模板组织语言

### 阶段 4：说明书撰写
- 背景技术：说透现有技术痛点
- 发明内容：三删一增扩写权利要求书
- 具体实施方式：三加法补充细节

### 阶段 5：审查意见答复
**三步法论证创造性**：
1. 确定最接近的现有技术
2. 找出特征区别，论述技术效果
3. 论证现有技术无技术启示

## 四、专利语言规范 - 拆→连→亮

### 描述零件与关系
```
第一步 拆：把复杂结构拆成单个零件
第二步 连：说清位置关系和连接方式
第三步 亮：用结构细节体现创新点
```

**位置关系精确表述**：
- "转轴 (4) 旋转密封地安装于壳体 (1) 的侧壁上"
- "高压喷嘴 (6) 位于 DPF 单元 (2) 的上方"

**连接关系明确分类**：
- 固定连接：一体式结构、焊接、螺栓连接
- 活动连接：转动连接、滑动连接
- 电性连接：信号连接、电性连接

### 常见错误及修正
| 错误类型 | 错误示例 | 正确示例 |
|---------|---------|---------|
| 模糊描述位置 | "转轴装在壳子上" | "转轴 (4) 旋转密封地安装于壳体 (1) 的侧壁上" |
| 漏写连接方式 | "导气环和壳体连在一起" | "导气环 (16) 与第二壳段 (11) 为一体式结构" |
| 亮创新点喊口号 | "本结构能免拆卸清碳" | "DPF 单元 (2) 活动安装于壳体 (1) 中，驱动总成驱动 DPF 单元转动..." |
| 模糊数值 | "高温"、"高压" | "80-120℃"、"0.8-1.2MPa" |

## 五、避坑指南

### 权利要求书避坑
- 避免多余限定导致保护范围缩小
- 避免标号不一致
- 避免引用关系错误（不反向引用、不循环引用）
- 避免模糊表述
- 避免功能化表述代替结构化表述

### 说明书避坑
- 背景技术只说优点不说痛点
- 发明内容与权利要求书完全一致（未扩写）
- 具体实施方式细节不足
- 附图与文字不对应
- 摘要字数超标或内容空洞

### 审查答复避坑
- 漏看审查员核心质疑
- 对比分析表面化（未分析技术效果差异）
- 答复逻辑混乱（未按"先形式后实质"顺序）
- 过度修改（超出原始公开范围）

## 六、实战案例

### 可折叠桌面收纳架

**创新点**：折叠设计 + 分类结构 + 防滑组件

**独立权利要求**：
```
1. 一种可折叠桌面收纳架，包括架体；
   其特征在于，还包括折叠杆、收纳格和锁扣；
   所述折叠杆的一端与架体的两侧转动连接，另一端与收纳格的侧边转动连接；
   所述锁扣固定在架体的顶部，用于折叠后固定收纳格的位置；
   所述收纳格可拆卸安装在折叠杆之间，形成用于放置物品的收纳空间。
```

**从属权利要求**：
```
2. 根据权利要求 1 所述的可折叠桌面收纳架，其特征在于，
   所述收纳格的底部设有防滑组件，所述防滑组件包括至少两个防滑垫，
   所述防滑垫分别粘贴在收纳格底部的四角位置，
   且防滑垫的下表面设有凹凸纹路。

3. 根据权利要求 1 所述的可折叠桌面收纳架，其特征在于，
   所述架体两侧与折叠杆连接的位置设有弧形限位块，
   所述弧形限位块的内侧设有缓冲垫。

4. 根据权利要求 1 所述的可折叠桌面收纳架，其特征在于，
   所述收纳格的内部设有至少一个可拆卸分隔板，
   所述收纳格的内侧壁设有若干卡槽，
   所述分隔板的两端设有与卡槽适配的凸起。
```

## 十、Word 文档生成规范（重要）

### 问题警示
**禁止使用 Write 工具直接创建 .docx 文件**——这会生成纯文本文件而非真正的 Word 文档，导致用户无法打开。

### 正确的文档生成方法

**方法一：使用 Python python-docx 库（推荐）**

```python
from docx import Document
from docx.shared import Pt, Cm
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml.ns import qn

def set_chinese_font(paragraph):
    """设置中文字体为宋体"""
    for run in paragraph.runs:
        run.font.name = '宋体'
        run._element.rPr.rFonts.set(qn('w:eastAsia'), '宋体')

# 创建文档
doc = Document()

# 标题
title = doc.add_paragraph('权利要求书')
title.alignment = WD_ALIGN_PARAGRAPH.CENTER
title.runs[0].font.size = Pt(16)
title.runs[0].font.bold = True
set_chinese_font(title)

# 添加内容
for claim in claims:
    p = doc.add_paragraph(claim)
    p.paragraph_format.line_spacing = 1.5
    set_chinese_font(p)

# 保存
doc.save('权利要求书.docx')
```

### 专利文档格式要求

| 要素 | 要求 |
|------|------|
| 字体 | 宋体（中文）、Arial（数字/英文） |
| 字号 | 标题 16pt/14pt，正文 10.5pt(五号) |
| 行距 | 1.5 倍行距 |
| 页边距 | 上下 2.54cm，左右 3.17cm |
| 纸张 | A4 |

### 验证步骤
生成后必须验证文件可正常打开：
```python
from docx import Document
try:
    doc = Document('文件名.docx')
    print(f'验证成功：{len(doc.paragraphs)} 段落')
except Exception as e:
    print(f'验证失败：{e}')
```

### 常见错误及修复

| 错误 | 原因 | 修复 |
|------|------|------|
| 文件无法打开 | 用 Write 工具创建 | 改用 python-docx |
| 中文显示乱码 | 未设置中文字体 | 调用 set_chinese_font |
| 格式丢失 | 未设置段落格式 | 显式设置 font.size 等 |
