# 工程评审汇报 18 页标准大纲模板

> 章节骨架可按项目裁剪；[方括号] 为待填占位符。数据一律取自设计图纸原件。

| 页 | 章节 | 内容要点 |
|---|---|---|
| P1 | 封面 | 项目全称、建设/设计单位、项目编号、日期、工程照片背景 |
| P2 | 目录 | 7 个部分 + 页码 |
| P3 | ① 项目概述 | 建设必要性（主桥深水区/复杂地形 → 临时钢栈桥）；功能定位（履带吊作业/重车通行/物资通道）；基本信息表 |
| P4 | ① 设计依据 | 国家及行业标准清单（JTG D60、GB 50017、JTG/T 3650 等）；参考资料清单 |
| P5 | ② 水文气象 | 设计水位/洪水位/通航水位、流速、冲刷深度；场地控制表 + 航拍图 |
| P6 | ② 工程地质 | 地层分布表（自上而下各层厚度与性状）；对沉桩/钻孔的影响；钻孔柱状图 |
| P7 | ③ 总体平面 | 总长/标准段宽、与主桥轴线关系、掉头平台；桥位平面图（图纸截图） |
| P8 | ③ 纵断面 | 桥面高程确定依据（洪水位+浪高+安全值）；纵坡；纵断面截图 + 桩长参数表 |
| P9 | ④ 上部结构 | 桥面系（花纹钢板+分配梁）、贝雷梁型号/跨径/片数；实景图（带构件标注）+ 材料用量表 |
| P10 | ④ 下部结构 | 下横梁、钢管桩排架（直径/壁厚/根数）、连接系；桥墩立面图纸 + 对比表 + 实景 |
| P11 | ④ 荷载标准 | 活载（汽车/履带吊接地比压）、恒载与环境荷载；大数字 KPI 卡 |
| P12 | ④ 结构验算 | 建模软件；主梁弯矩/剪力/应力比；单桩反力与入土深度；单桩承载力柱状图 + 材料汇总 |
| P13 | ⑤ 施工工艺 | "钓鱼法"6 步循环流程 + 沉桩实景 + 工艺示意 |
| P14 | ⑤ 关键节点 | 岸接端处理、通航孔特殊设计、防撞设施；节点大样图带（1:25/1:50） |
| P15 | ⑥ 风险分析 | 风险矩阵表（编号/风险点与成因/等级/控制措施），风险用橙色标识 |
| P16 | ⑥ 安全设施 | 护栏/通道/警示设施实景 + 设施数量表 |
| P17 | ⑦ 总结 | 4 条结论卡 |
| P18 | ⑦ 提请评审 | 提请评审事项（如实标注图纸疑点：如高程基准不一、牌号标注不一致）+ 致谢 |

## 每页信息密度

1 主视觉（图/表/大数字）+ ≤1 段要点（3–5 条）；禁止整页文字。
