# 中文 PPT 避坑清单

> 来源：本项目 v2 检查修正记录 + PPT制作规范 + 社区中文 PPT skill 经验汇总。

## 字体

- **思源黑体非 Windows 内置**：评审机未装会整体回退主题字体、版式全乱。交付必须嵌入字体（文件 > 选项 > 保存 > 嵌入字体）或随附 .otf 文件。
- **不设字体的 run 一律补齐**：python-pptx 新增 run 默认不指定字体，会回退主题字体（通常为 Calibri/宋体），中英文混排时尤其明显。
- **西文不另引 Helvetica**：复用思源黑体自带 Latin 字形，避免混入第二字体体系。
- **字号下限**：正文 ≥12.5pt（远距可辨基线）；表格 11.5–12.5pt；换行会叠行的表才降 11.5。

## 配色

- 同一语义蓝色 ≤2 种，禁止 3 种及以上并存（本项目踩坑：1E6FB8/2563EB/2E8CC9 并存 → 统一为 0D348B/45A7E0）。
- 禁止红/绿/金等多色相混用；点缀色仅橙 1 个，仅用于风险警示。
- 色值只在主题层定义，禁止在 run 上写死色值——否则换色系无法一键同步。
- 正文禁用纯黑，用深灰（如 #333333 / 深蓝灰 #17293F）。

## PPTX 文件完整性（防"打不开/已损坏"）

- 交付前必须跑 officecli validate（OpenXML 校验），0 错误才可交付。
- **图表轴 ID 必须归一化**：python-pptx 多图表同页时 category/value 轴 ID 易冲突，导致 PowerPoint 报修复；生成后检查并统一。
- 重建幻灯片会丢失动画、SmartArt 等扩展内容——编辑既有 PPT 时只改请求的内容，保存为新文件。
- 图片用本地资产，不用网络 URL（打开时离线即裂图）。

## 版式

- 用 lint 脚本自检文字溢出/越界/重叠/安全区；逐项修正到 PASS 再进人工目检。
- 折行孤字标点要修整；封面/目录/尾页编号徽标易与装饰块遮挡，逐页确认。
- 禁止手工摆装饰线/色块——装饰进版式层（Slide Layout），内容进组件层，保持可复现。
