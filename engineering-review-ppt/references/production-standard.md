# 工程类评审汇报 PPT 制作规范（v1.0）

> 依据《福永河钢栈桥施工图评审汇报》实际制作过程沉淀
> 适用范围：桥梁/栈桥/隧道等土木工程类，面向专家评审、建设方汇报的场景
> 目标：专业、严谨、数据可溯源、可编辑、制作可复现
> 双重用途：§3.1/§3.2/§4 为 AI 消费配方（供 LLM 自动产出 build.py 与页面）；§5/§6 为人工复核清单（成稿后逐项核对）
> 边界：仅适用"评审/汇报类工程 PPT"；不适用营销 PPT、产品白皮书、非工程类汇报、纯数据大屏

---

## 1. 定调与原则（先立规矩再动手）

1. **数据唯一源**：所有设计参数、型号、数量、高程、坐标必须取自设计图纸原件；其他参考文件（施组、方案）只用于印证工艺术语，**严禁混入其工程数据**。
2. **成果为纲**：成稿前先定义"成功标准 = 打开后每一页观众一眼能看懂、字能看清、数据与图纸一致"，过程指标（渲染成功/校验通过）不等于完成。
3. **三层优先级**：**能配图不用表格，能用表格不用文字**（图片 > 表格 > 短句）。
4. **能模板化的一律模板化（元原则）**：一切可复用的样式都上移成"模板/主题"，逐页只落"内容"；目标是**换色系/换字体全篇一键同步**。按三层下沉：**① 主题层**——自定义字体 + 自定义主题颜色（见 §1.6），改色系/换字体一处改、全篇生效；**② 版式层**——Slide Layout 承载标题栏/标签/页脚装饰；**③ 组件层**——build.py 组件函数（panel/kpi/table/pic_round/risk）生成同构块。禁止手工摆装饰线/色块、禁止在 run 写死色值。
5. **配色 ≤3 色相**：蓝（主色系，含深浅）+ 中性色（白/浅灰蓝/深灰）+ 橙（仅风险警示）。
6. **字体与配色模板化（自定义主题）**：字体通过“自定义字体”统一（设计 > 字体 > 自定义字体），颜色（主色/背景/点缀/文字）通过“自定义主题颜色”统一（设计 > 颜色 > 自定义颜色）。正文/标题/主题色/背景/点缀均在主题层定义，禁止在页面 run 上单独设字体或写死色值。

## 2. 内容结构（18 页标准骨架，可按项目裁剪）

| 页 | 章节 | 内容要点 |
|---|---|---|
| 1 | 封面 | 项目名+全称、建设单位/设计单位、项目编号、日期、工程照片背景 |
| 2 | 目录 | 7 个部分 + 页码（P3 P5 P7 P9 P13 P15 P17） |
| 3–4 | ① 项目概述与设计依据 | 基本信息表（7 行）+ 效果图 + 规范标准两张表 |
| 5–6 | ② 地质与水文 | 场地控制表 + 航拍图；地层分布表 + 钻孔图（柱状图） |
| 7–8 | ③ 总体布置 | 桥位平面图（图纸截图）+ 跨径/墩台布置；纵断面截图 + 桩长参数表 |
| 9–12 | ④ 结构设计（含验算） | 上部：实景图（带构件标注）+ 材料用量表；下部：桥墩立面图纸 + 桥墩/桥台对比表 + 实景；荷载标准大数字卡（吨位/承载力）+ 质量控制指标表 + 材料控制表；单桩承载力柱状图 + 材料汇总卡 |
| 13–14 | ⑤ 施工工艺 | 钓鱼法 6 步流程 + 沉桩实景 + 钻孔示意；节点大样图带（螺栓/限位器/桥面布置 1:25/1:50）+ 构造要点 |
| 15–16 | ⑥ 风险与安全 | 风险矩阵表（编号/风险点与成因/等级/控制措施）+ 风险色；护栏/防护实景 + 设施数量表 |
| 17–18 | ⑦ 总结与评审 | 4 条结论卡；提请评审事项（**如实标注图纸疑点**：高程基准不一、钢筋牌号标注不一致）+ 致谢 |

**每页信息密度**：1 主视觉（图/表/大数字）+ ≤1 段要点（3–5 条）。禁止整页文字。

## 3. 视觉规范

### 3.1 配色（本类项目采用"工程蓝"体系）

当确定 PPT 的【主题/行业/受众】时，请按照以下步骤输出一套专业的 PPT 配色方案：
1、确定主色调 (Dominant Color - 30%)
  - 结合行业属性和情感基调，选择1个核心主色。
  - 输出该颜色的 HSL 和 HEX 色值。
  - 其他辅助颜色遵循 HSL色系的H（色调）按梯度颜色公式：12.8 × n 加减，其他点缀颜色可以通过修改HSL色系中的L（亮度），且原则上颜色梯度不要超过60。
  - 简述该颜色传递的视觉情绪（如：科技感、严谨、活力）。

2、选定背景色 (Background Color - 60%)
  - 根据主色，匹配1个高净度的背景色（浅色调如暖白/浅灰，或暗色调如深蓝/极夜黑）。
  - 确保全篇具备极高的阅读留白感。

3、提取点缀色 (Accent Color - 10%)
  - 挑选1个与主色形成强烈对比的亮色，专用于核心数字、图标或高亮文本。
  - 确保其在背景和主色衬托下具有极强的视觉冲击力。

4、规范文字与文本层级 (Text & Neutral)
  - 规定正文字体颜色（禁止纯黑，推荐深灰，如 #333333）。
  - 规定次要信息/辅助线的灰度等级。

**颜色定义方式**：用主题颜色

**禁止**：红/绿/金等多色相混用；同一语义蓝色 ≤2 种、禁止 3 种及以上混用（本次踩坑：1E6FB8/2563EB/2E8CC9 三种蓝并存 → 统一为 0D348B/45A7E0 两种）。

### 3.2 字体

- **全篇统一思源黑体体系（Source Han Sans）**：
  - 标题：思源黑体 Bold
  - 正文：思源黑体 Regular
  - 西文复用思源黑体自带 Latin 字形，不另引 Helvetica（避免混入第二字体体系）
- 不设字体的 run 一律补齐，避免回退主题字体。
- **交付须嵌入字体**：思源黑体非 Windows 内置，评审机未装会整体回退主题字体；导出勾选"嵌入字体"或在交付物附带 .otf。

### 3.3 字号分级（本类项目最小可读基线：正文 12.5pt，观众远距可辨）

**尺寸约定**：长度单位 cm；版式坐标多值写法 `left/top/width×height`（先位置后大小，与 python-pptx Inches/Cm 一致）。

| 元素 | 字号 | 备注 |
|---|---|---|
| 页面标题 | 24pt 粗 | 左侧 0.12×0.62 亮蓝竖条 |
| 章节标签 | 12pt 白粗 | 单行；标签框 24.30/1.08/7.65×0.94、margin 0；右端 0.80 深蓝直角补块 |
| 面板标题 | 14pt 粗 | |
| KPI 大数字 | 27pt（单位 12.5） | 数字越大越好 |
| 正文要点 | **12.5–13pt** | ≥12.5 起步；13 用于宽松页 |
| 表格正文 | 11.5–12.5pt | 12.5 优先；换行会叠行的表降 11.5 |
| 步骤圆形序号 | 10.5pt | **>11 必换行**（圆内净宽≈0.8cm，11.5pt 的"01"即竖排——本次踩坑） |
| 注释/注 | 12.5pt | |
| 页脚 | 10pt | 项目名 + 页码 XX/18 |

**规则**：所有"正文/说明"不得 <12.5pt（页脚/圈号/降档表除外）；升级字号后**必须重算容器高度**（见 §5 质检）。

### 3.4 版式与形状

- **内容页版式引用 Title Only**；Blank 版式保持原生（本次踩坑：装饰加进 Blank → 目录页被污染）。
- **大容器/照片框一律直角**（roundRect adj=0）；仅小标签卡保留细圆角(0.12)。
- **删除所有装饰性色块**：页顶渐变条、标题左渐变长条、标签渐变底、标签右补块（由版式提供后页面勿重复）、KPI 卡顶渐变线、图片说明覆盖细条。
- 面板结构：白底直角 + 左侧 0.15 纯蓝竖条（深蓝）+ 顶部 0.98 浅蓝标题条（EAF3FC）。
- 图片：近直角 + 白细框；说明条 0D348B 白字；图纸截图"cover 裁切"保证不丢标注。

## 4. 制作工艺与制作流程（推荐管线）

1. **数据提取**（PDF→图片/文字）：图纸逐页高清渲染 220dpi + OCR/视觉识别参数表 → 建"参数核对清单"（25 项，逐项回注图号）。
2. **大纲与逐页 brief（JSON）**：每页 title/summary/takeaway/items（label+value+displayValue+**detail**）——brief 必须带 detail（本次踩坑：投影取 detail，缺 detail=空白）。
3. **生成源脚本 build.py**（python-pptx，可复现）：配色常量/组件函数（panel/kpi/table/pic_round/risk）——不逐页手工摆。
4. 生成 → officecli validate（0 错误）→ PowerPoint 原生渲染逐页 PNG。
5. 质检（§5）→ 修正 → 重渲染 → 目检+视觉工具核查 → 定稿。
6. 交付：pptx + 每页预览 PNG + 源脚本 + 数据来源说明。

**模板化实施要点（版式承载装饰）**：
- 版式（Title Only）放：竖条/标签蓝块/补块/页脚线/页脚项目名（静态）；页面仅：标题、章节文字、页码、正文。
- 切换页面版式引用用关系目标替换（rel._target = layout.part），勿 drop+add 关系（会致 PowerPoint 拒开）。

## 5. 质检清单（渲染后逐项过）

- 配色：仅规范色值（抽查全文件填充色/文字色统计，无二义蓝）
- 字体：100% 思源黑体（字体分布统计 fonts={"思源黑体": N}；剔除未嵌入所致的回退项）
- 字号：正文 ≥12.5；无异常小字（<12 仅页脚/圈号/降档表）；统计分布复核
- 无文字重叠：标签单行、页脚与页码不重叠、表格行不叠行（行高=ceil(行数×0.62)重算）
- 无溢出：文本块高度估算（行数×字号×1.34×0.0353cm vs 容器高），越界即降档或删条
- 圆内序号单行（≤10.5pt 稳妥）
- 每页 1 主视觉、无残留装饰线/色块、页脚页码正确
- 数据一致性：抽查 5 个大数（93.0m / 9.0m / (18+5×15) / Φ800×10 / 850kN）vs 图纸
- 图纸疑点如实标注（如高程基准 1985 vs 1956、HPB400 vs HPB300/HRB400）并列入评审事项——**不帮设计方"假装一致"**
- officecli validate（或 PowerPoint 打开）无损坏

## 6. 踩坑速查（防复发）

| 坑 | 原因 | 对策 |
|---|---|---|
| 正文 11/12pt 观众看不清 | 原字号体系偏小 | 基线提到 12.5–13 |
| 圆内"01"竖排 | 11.5pt 宽接近圆内净宽 | 圈号 ≤10.5pt |
| 表格行叠行 | 12.5pt 换行后行高不足 | 行高按换行重算；超限降 11.5 |
| 页脚文字与页码重叠 | 页脚文字加大后超出位置 | 页脚 10pt 且与页码框无交集 |
| 页面残留装饰 | 手工元素未随模板化删除 | 版式承载 + 页面元素清除清单逐条核对 |
| 装饰误进 Blank 版式 | 内容页与目录共版式 | 内容页引用 Title Only；Blank 保持原生 |
| 自造版式 XML 致 PowerPoint 拒开 | 元素 id/顺序/占位符 XML 不规范 | 用"页面元素 deepcopy→版式"或新版式模板；最终以 PowerPoint 打开为准 |
| 工具链"过程成功≠成果可用" | 只验证了渲染管线 | 每阶段以"观众打开看到什么"验收 |
| 第三方 skill 适用边界 | 预览器内置示例层、导出需桌面浏览器、沙箱限制 spawn | 明确边界后再承诺；交付前用桌面端实测一次 |
