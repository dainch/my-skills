# 高频条款与检索路径

> 本节只做「问题 → 条号」定位，条文原文见 `references/`。不重述法条、不下结论。
> 引用时打 `[法条原文]` 标签，并提示核对时效与司法解释。

## 合同纠纷

- 合同成立与生效 → 第 502–508 条
- 合同无效（违反强制性规定 / 违背公序良俗）→ 第 153 条
- 格式条款 → 第 496–498 条
- 免责条款无效 → 第 506 条
- 违约责任 → 第 577–594 条
- 违约金 → 第 585 条
- 定金 → 第 586–588 条
- 借款合同 → 第 667–680 条
- 借款利息不得预先扣除 → 第 670 条
- 禁止高利放贷 / 利率 → 第 680 条
- 保证合同（方式 / 责任 / 从属性）→ 第 681–702 条

## 担保物权（债务担保）

- 担保物权定义与优先受偿 → 第 386 条
- 抵押权 → 第 394 条起（第十七章 抵押权）
- 质权 → 第 425 条起（第十八章 质权）
- 留置权 → 第 447 条起（第十九章 留置权）

## 诉讼时效与期间

- 普通诉讼时效（3 年）→ 第 188 条
- 分期履行债务的时效 → 第 189 条
- 时效中止 → 第 194 条
- 时效中断 → 第 195 条
- 期间计算 → 第 200–204 条

## 侵权责任

- 过错责任 → 第 1165 条
- 无过错责任 → 第 1166 条

## 常见抗辩切入点（仅定位，不下结论）

- 超过诉讼时效 → 第 188 条
- 格式条款不成为合同内容 / 无效 → 第 496–497 条
- 违约金过高，请求减少 → 第 585 条
- 利率违反国家有关规定 → 第 680 条
- 主合同无效导致保证合同无效 → 第 682 条
