# 民法典法条检索 —— 项目级配置（civil-code）

> 本文件是 `civil-code` 技能读取的实践级配置。本技能由 `book-to-skill` 从《中华人民共和国民法典》
> 全文新生成，本文件定义它自身的「来源溯源标签 / 法条引用纪律 / 时间触发」规则，独立运行，
> 不依赖项目内其他技能。可直接使用。

**默认适用场景：** 需要引用或核对《民法典》条文原文，为诉讼文书、要件分析、质证意见等提供法条依据；同时对法条时效与司法解释作提示。本技能保持中立，不预设当事人立场。

**角色：** 非律师但有律师支持。如为执业律师，改此行为「执业律师/法律专业人士」。

## 来源溯源标签体系

| 标签 | 含义 | 可信度 |
|------|------|--------|
| `[法条原文]` | 直接引用法规条文原文（本技能 `references/` 内，以 2021-01-01 施行版为准） | 最高 |
| `[裁判文书]` | 来源于具体裁判文书 | 高 |
| `[联网检索 — 需复核]` | 联网搜索获取，未二次验证 | 中低 |
| `[本地知识库]` | 来源于本地文件 | 中，注意时效 |
| `[模型知识 — 需验证]` | 来源于模型训练数据，未独立核实 | 低 |
| `[用户提供]` | 用户直接提供 | 依用户判断 |
| `[已验证 — YYYY-MM-DD]` | 曾在标注日期完成独立核实 | 高，注意时效 |

## 法条引用纪律（强制）

1. **逐字准确。** 引用法条必须逐字与 `references/` 原文一致，不转述、不概括、不改写标点。
2. **条号可追溯。** 每条引用附「编/章/条号」，可回 `references/0X-*.md` 定位。
3. **时效核对。** 引用前提示：本技能条文为 2020-05-28 通过、2021-01-01 施行版本；
   司法解释、地方口径、后续修订（含《民法典合同编通则司法解释》等）需另行核对。
4. **不下结论。** 不认定合同效力、责任、胜诉与否；需法律评价处标注 `[需审查]`。

## 时间触发（强制）

以下情形必须提示另行独立检索，不得仅依赖本技能条文作终局结论：
1. 涉及具体司法解释（如合同编通则解释、民间借贷司法解释）
2. 涉及诉讼时效、申请执行时效的具体起算与中断/中止
3. 涉及地方性法规、地方司法口径
4. 涉及案例作为裁判倾向参考
