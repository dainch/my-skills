# /civil-code

1. 加载技能目录下 `config/CLAUDE.md` → 角色、成果标头、来源溯源标签、法条引用纪律。缺失则回退内置默认并继续（不阻断）。
2. 定位检索需求（编名 / 条号 / 主题 / 关键词），从下方「编索引」「主题索引」定位到 `references/` 对应文件。
3. 读取对应 `references/0X-*.md`，按「编→分编→章→节→条」逐条核对，返回**法条原文**（逐字，不转述、不概括）。
4. 引用时打来源标签：本技能内条文为 `[法条原文]`（以 2020-05-28 通过、2021-01-01 施行版本为准）；引用前提示核对时效、司法解释与后续修订。
5. 不下结论、不替代法律意见；金额/日期/主体等事实回归案件材料。

## 本法概况

《中华人民共和国民法典》由第十三届全国人民代表大会第三次会议于 2020 年 5 月 28 日通过，
自 2021 年 1 月 1 日起施行。共 **7 编 + 附则，1260 条**。施行之日，《婚姻法》《继承法》
《民法通则》《收养法》《担保法》《合同法》《物权法》《侵权责任法》《民法总则》同时废止。

## 本技能不做什么

- **不概括、不转述法条**：只给逐字原文 + 条号定位。
- **不下结论**：不认定合同效力、责任、胜诉与否。
- **不替代法律检索**：司法解释、地方司法口径、修订与废止需另行核对。
- **不编造数字**：金额、日期、主体回归案件材料。
