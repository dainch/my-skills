# 应诉知识经验库（网贷 / 金融借款纠纷）

> **性质**：`loan-defense` skill 的操作性知识副本（由 `references/knowledge-base.md` 承载），与工作区根 `应诉知识经验库.md` 同源。改动时两者同步；以本副本作为 skill 运行时读取的来源。
> **免责声明**：本文档为知识梳理与经验沉淀，**不构成正式法律意见**。涉及起诉、答辩、和解、签署、处分权利等法律行为，应由**执业律师**复核并代表当事人作出最终决定。文中"话术""文书表述"供参考，具体以个案事实与法院认定为准。

## 〇、使用指引（供后续 LLM / 使用者快速上手）

本库是"**场景 → 打法**"型知识，不按法条罗列，而是按"你正在面对什么"组织。使用步骤：

1. **先定位场景**：判断当下是哪一种情况（催收骚扰 / 冻结 / 支付令 / 仲裁 / 起诉 / 债权转让 / 征信代偿 / 信用卡退费 / 骚扰短信），跳到对应章节（见第三节）。
2. **再取法律依据**：每个场景手册已内嵌对应法条；如需更全，查第二节"法律依据库"。
3. **拿证据 + 话术 + 文书**：第三节每场景均给出"判断信号 / 应诉步骤 / 法律依据 / 话术或文书模板 / 注意事项"，可直接组合使用。
4. **遵守通用原则**：见第五节"通用抗辩与谈判武器库"、第六节"风险红线"，是跨场景的底座。
5. **遇模糊处查第七节**：本库对源笔记中表述不准、适用范围受限或无法完全确认的条目，一律以"⚠️待核实"标注，不作为行动依据。

**铁律**（每场景通用）：
- **积极应诉，绝不缺席**。缺席判决几乎必然支持对方，且丧失全部抗辩与调解机会。
- **拒绝逃避，保留证据**。合同、放款流水、还款流水、催收短信/录音、APP 截图全部留存。
- **先比数字，再谈态度**。一切主张先回归"放了多少、还了多少、还剩多少本金"。
- **以"本金"为锚**，罚息/违约金/杂费一律单独拆出来质疑。

## 二、法律依据库（按主题组织）

### 2.1 隐私权 / 人格权
- **《民法典》第1032条**：自然人享有隐私权，任何组织或个人不得以刺探、侵扰、泄露、公开等方式侵害他人隐私权。
- **《民法典》第1033条**：除法律另有规定或权利人明确同意外，任何组织或个人不得实施下列行为——(1) 以电话、短信、即时通讯工具、电子邮件、传单等方式侵扰他人私人生活安宁；(2) 进入、拍摄、窥视他人住宅、宾馆房间等私密空间；(3) 拍摄、窥视、窃听、公开他人私密活动；(4) 拍摄、窥视他人身体私密部位；(5) 处理他人私密信息；(6) 以其他方式侵害隐私权。
- **《民法典》第1034条**：自然人个人信息受法律保护。

### 2.2 个人信息保护
- **《个人信息保护法》第13条**：处理个人信息应符合法定情形（含取得个人同意、为订立/履行合同所必需等）。⚠️ 源笔记用于反驳骚扰短信的合法性论证，需结合具体场景判断。
- **《个人信息保护法》第15条**：基于个人同意处理个人信息的，个人**有权撤回同意**；撤回不影响撤回前已进行的处理活动效力。→ 可要求撤回"授权第三方催收"。
- **《个人信息保护法》第23条**：个人信息处理者向其他处理者提供其处理的个人信息时，应**告知接收方名称、联系方式、处理目的、处理方式**，并**取得个人同意**。→ 银行委托第三方催收，须向本人披露第三方信息并取得同意。

### 2.3 催收合规
- **《刑法》第293条之一（催收非法债务罪）**：有下列情形之一，催收高利放贷等产生的非法债务，情节严重的，处三年以下有期徒刑、拘役或管制，并处或单处罚金——(1) 使用暴力、胁迫；(2) 限制人身自由或侵入住宅；(3) 恐吓、跟踪、骚扰他人。**[修正：源笔记误写"第293条"，实为第293条之一，系《刑法修正案(十一)》新增]**
- **《互联网催收自律公约》第13条、第16条**：催收对象应符合法律法规要求，不得骚扰无关人员；沟通使用文明礼貌用语，不得恐吓、威胁、辱骂或违反公序良俗。
- **《互联网催收自律公约》第18条**：催收人员不得向债务人以外的其他人透露债务人负债、逾期、违约等个人信息，法定情形除外。
- **《互联网催收自律公约》第26条**：催收人员不得冒用行政部门、司法机关及其他任何机构或个人名义开展催收。**[修正：源笔记"司下机关"→"司法机关"]**
- **《金融机构个人消费类贷款催收工作指引（试行）》**（中国银行业协会，**2026-01-30 施行**，共七章五十四条）：适用于个人消费贷款，会员单位受约束。明确禁止夸大债务数额（第25条）、要求如实告知欠款金额（第23条）；对困难债务人申请分期，机构**应当审核答复，不应直接粗暴拒绝**。→ 这是"消费贷个性化分期"的主要依据（区别于信用卡的 70 条）。

### 2.4 合同 / 格式条款
- **《民法典》第496条**：格式条款提供方未尽合理提示或说明义务，致使对方没有注意或理解与其有**重大利害关系**条款的，对方**可以主张该条款不成为合同内容**。
- **《民法典》第497条**：格式条款**不合理地**免除或减轻自身责任、加重对方责任、限制对方主要权利，或**排除对方主要权利**的，该条款**无效**。
- **《民法典》第498条**：对格式条款有两种以上解释的，应作出**不利于提供格式条款一方**的解释。
- **《合同法》第79条、第80条**（现并入《民法典》第545、546条）：债权人可转让债权，但应按约定/法定除外情形；**转让权利应当通知债务人，未经通知，该转让对债务人不发生效力**。⚠️ 原《合同法》已废止，实务建议直接引《民法典》第545、546条。

### 2.5 金融监管 / 消费者权益
- **《商业银行信用卡业务监督管理办法》第70条**：特殊情况（欠款超出还款能力 + 仍有还款意愿）下，发卡行可与持卡人平等协商达成**个性化分期还款协议，最长不超过5年**（60期）。**[明确：仅适用于信用卡，不当然适用于消费贷/网贷；消费贷见 2026《催收工作指引》]**
- **《中国人民银行关于信用卡业务有关事项的通知》**（涉第三、六条部分收费/滞纳金规范）。
- **《中华人民共和国消费者权益保护法》第8条**：消费者享有知悉其购买、使用的商品或接受服务的真实情况的权利。
- **《银行保险机构消费者权益保护管理办法》**：金融机构应保障知情权，服务收费应明码标价并履行告知义务。

### 2.6 民事证据 / 程序 / 时效
- **《民事诉讼法》第67条**：当事人对自己提出的主张有责任提供证据；因客观原因不能自行收集、或法院认为审理需要时，法院应调查收集；法院应全面、客观审查核实证据。
- **诉讼时效**：民事案件一般诉讼时效**3年**，自权利人知道或应当知道权利受侵害之日（通常为还款逾期日）起算。超过时效可抗辩拒绝履行。
- **小额诉讼程序**：一审终审，无法上诉；通常举证期较短，调解是唯一能实现灵活还款的途径（判决主文只能"一次性支付"）。

### 2.7 电子签名
- **《电子签名法》第13、14条**：可靠的电子签名需由第三方认证；符合条件者与手写签名具有同等法律效力。可据此要求平台提供**电子签名认证证书**、第三方存证报告、人脸识别完整音视频等。

## 三、场景应诉手册（核心）

### 场景A：暴力 / 违规催收（短信、电话、爆通讯录）

**判断信号**：言语恐吓、辱骂、威胁人身安全；骚扰亲朋/单位（爆通讯录）；冒充公检法/央行；向无关第三方透露欠款；频繁电话轰炸。

**应对步骤**：
1. **固定证据**：保留短信原文、通话录音、骚扰亲友的截图，记录时间、号码、内容。
2. **明确边界**：只与本人沟通，对方骚扰亲友即违法（民法典1033、1034；催收自律公约18条）。
3. **要求撤回授权**：依个保法15条，书面要求撤回"授权第三方催收"；依23条，要求对方披露第三方机构信息并取得本人同意。
4. **分级举报**：运营商举报（见第一节）→ 行政投诉（12378/12363/12345/12315）→ 网络举报（12377/12321）。
5. **涉暴力/恐吓**：转公安 12110 / 110 报案；情节严重的，对方可能构成**《刑法》第293条之一 催收非法债务罪**。

**法律依据**：民法典1032/1033/1034；个保法13/15/23；刑法293之一；互联网催收自律公约13/16/18/26。

**注意**：所有举报留存回执；不要与对方对骂，避免被反咬"恶意欠款"。

---

### 场景B：微信 / 支付宝 / 银行卡被冻结

**关键第一步**：确认是**财保**还是**执保**。
- **财保（诉前财产保全）**：临时性冻结，若无进一步正式起诉，一般 **15–30 天自动解冻**。属程序性措施，可评估法律风险。
- **执保（执行保全/执行阶段）**：已进入实质性诉讼/执行环节。

**应对步骤**：
- **财保**：若对方未起诉，等待自动解冻；若担心，可主动联系法院/对方了解是否已立案。
- **执保**：**冻结后15日内**提交《管辖权异议民事裁定申请书》，**10日内解冻**（对方撤诉或法院裁定）。
- **账户冻结且影响生活**：向法院申请保留**必要生活费用**（依据执行程序中生活费保障规定）。

**提示**：先核实是哪一类（看法院文书是"诉前财产保全"还是"强制执行"）；执保阶段尤其要**避免缺席**，否则判决+执行会同步推进。

### 场景C：收到法院**支付令**

**判断**：法院发出的督促程序文书，催促债务人限期清偿，可能不经开庭即生效。

**应对**：收到后**立即写《异议书》**，质疑平台违规收费、利息超标、金额不实等。**提出异议后，支付令在3日内失效**，督促程序转为诉讼程序，从而争取到开庭答辩的机会。

**法律依据**：民事诉讼法督促程序相关规定。

**注意**：**不要不作回应**。支付令生效后可申请强制执行，届时抗辩空间已丧失。逾期不提异议 = 默认接受。

---

### 场景D：信用卡不合理费用（年费 / 分期 / 增值服务 / 罚息 / 循环息）

**判断**：被扣了不知情的费用（年费、自动分期手续费、增值服务费、罚息、违约金等）。

**应对步骤（退费三步法）**：
1. **致电信用卡客服**：要求列出 **自开卡至今** 全部费用——最低还款产生的息费、分期手续费、贷款/贷款分期手续费、逾期违约金、年费、权益费、循环利息、罚息等，逐项要求**减免/返还**。
2. **客服拒绝 → 要求反馈上级**：主张"这些费用我要求返还"。
3. **客服经理称"合理合法" → 三连抗辩**：
   - "**我不知情的情况下费用就被扣除了**，银行没有履行告知义务，我有知情权"；
   - "该部分年化利率多少、如何计算，我都有知情权"；
   - 不同意则**要对方工号**，拨打 **12378** 投诉，追溯到底。

**法律依据**：消费者权益保护法第8条；银行保险机构消费者权益保护管理办法；民法典496格式条款（未提示说明→不成为合同内容）；央行关于信用卡业务有关事项的通知。

**投诉事实与理由模板（要点）**：
- 本人系该行信用卡用户（卡号后四位：____）。**（日期）**查询账单发现被扣除 **（金额）** 元费用，项目名称 **（如：年费/自动分期手续费/增值服务费）**。
- **事实**：(1) 扣费前未通过短信/电话/APP弹窗等任何有效方式告知收费标准、扣费时间、服务内容；(2) 未经本人二次确认或主动勾选；(3) 即便合同有格式条款，银行未对涉重大利益条款"显著提示""明确说明"（民法典496）。
- **诉求**：(1) 3个工作日内退还 **（金额）** 元；(2) 若有逾期或利息，撤销征信逾期记录并冲抵罚息；(3) 书面/电话解释并道歉；(4) 整改告知机制。

### 场景E：征信出现"**代偿**"

**判断**：征信上出现"代偿"记录（多因担保/保险机构代偿，或平台违规上报）。

**原则**：**不要找代偿公司，先找原贷款机构。**

**三步处理**：
1. **联系原贷款机构**要求解除"代偿"，不要找代偿公司。
2. **书面提交申请诉求**（官方邮件或客服系统）；**3–7 天无回复**。
3. **直接投诉人民银行征信中心**（12363）。

**法律依据**：根据征信管理条例，未经本人授权擅自上报代偿属违规操作。⚠️ 具体条款建议以现行《征信业管理条例》为准核对。

---

### 场景F：收到网贷**仲裁**通知（虚假 vs 真实）

**先说结论**：仲裁裁决**不具备强制执行性**，最终有效性须经法院裁决确认（申请强制执行需向法院）。即便仲裁对你不利、判了不合理利息/杂费，法院也未必认可。

**区分三类，分别应对**：

**① 先予仲裁（旧模式）**：
- 特征：在借贷纠纷发生**之前**就已出具裁决书（"假设违约"式），违约后直接申请法院强制执行。
- 处置：**完全无需理会**。最高法已批复——法院对先予仲裁**裁定不予受理**；已受理的**裁定驳回执行申请**。

**② 网络仲裁（现行主流）**：
- 特征：立案、受理、审理、裁决、送达全流程在线完成。
- 应对：不要慌张，积极应对，依法向仲裁机构或执行法院提出异议，审查是否出现以下情形——
  1. 协议中含"放弃答辩、提交证据、提出反请求、撤销裁决"等权利的**排除条款**（违反《合同法》/民法典公平原则）；
  2. **实际取得金额明显低于协议载明债权**，含砍头息、阴阳合同、变相服务费等**变相提高利息**；
  3. 平台**无金融特许经营执照 / 超范围经营**，仲裁机构未严格审查债权人资质；
  4. 平台存在**暴力催收**等侵权违约行为；
  5. **违反仲裁流程**，未有效通知当事人，或未保障申仲员回避、质证、答辩等基本权利；
  6. 平台**单方发起仲裁，无双方事先约定**。

**③ 收到仲裁通知后（整体应对流程）**：
1. 积极获取对方申请材料 **+ 找到自己的原始借款合同**；
2. 梳理自己**应还的法定最高标准**；
3. 按当前还款能力确定**分期或减免结清计划**；
4. 主动沟通能否**提前调解**，按计划促成；
5. 达成调解，签订调解书，案件终止；
6. 若对方主张费用过高或无力偿还，一定积极应对；
7. 拿到仲裁裁定书且无力偿还的，可向**仲裁委所在地中级人民法院申请撤销裁决**，避免被对方快速强制执行。

**防虚假仲裁（识别真假）**：
1. 查看仲裁文件是否有**案件号、仲裁你的公司、当地仲裁委名称**等信息；
2. 在**仲裁委官网**查询案件编号能否查到自己的案子；
3. 在**企查查/天眼查**查该机构标签——属于"**社会组织**"还是"**事业单位**"。标为"**事业单位**"要多重视。
4. **若为虚假仲裁**，及时向相关机构举报；造成恶劣影响的，可向公安机关报案。

**话术要点**：仲裁归仲裁；进入法院环节，若存在超国家标准利息，法律会免去多余部分（只还标准利息）；对方要求不合理利息/杂费，即便过了仲裁，也过不了法院这一关。

### 场景G：收到网贷平台**起诉**通知

**应对步骤**：
1. **签收法院文书**：主动签收应诉通知书、开庭传票等，了解案件进展与诉讼请求，**避免拒收导致公告送达或缺席判决**。
2. **管辖权异议**：若起诉法院非本地，收到应诉通知后 **15日内** 提交《管辖权异议申请书》，要求移送本地法院；部分平台可能因异地成本高而撤诉。**[注意：若法院本来就你有权，提异议会浪费程序资源，应提前评估（见第六节）]**
3. **收集证据**：
   - **合同问题**：是否存在砍头息、捆绑保险费、电子签名无效；要求平台提供**电子签名认证证书**，无法提供或证书机构不正规 → 合同可能无效；
   - **要求提供账单明细**：息费怎么收，是否超国家上限；
   - **当庭索要放款流水**：看与合同是否一致；
   - **索要各类费用凭证**：担保费、保险费、服务费，查不合理项目；
   - **让对方证明资金来源合规**（针对网贷公司）；
   - **债权转让**：须出示完整合法转让文件（若打包转让给第三方，要提供**转让流水、转让证明、代偿流水与证明**，拿不出第三方须撤诉）；
   - **追问借款全流程**：是否存在夸大宣传、隐瞒费用等违规；
   - **请法院核验对方人员委托手续是否齐全**。
4. **提交答辩状**：收到起诉状副本后 **15日内** 提交，针对性反驳；可承认部分请求，或提出反诉（若平台违约）。
5. **申请保障最低生活费用**：账户被冻结时，向法院申请保留必要生活费。
6. **协商还款**：主动沟通分期/减免；部分平台可能因协商成本高而撤诉。
7. **委托律师**：案件复杂（债权多次转卖、金额较大）建议专业律师介入。

**注意**：积极应对，**避免逃避**；保留全部证据；不熟悉程序可咨询律师或法援（12348）。

### 场景H：收到**债权转让**后的起诉通知（受让方起诉）

**法律依据**：民事诉讼法第67条（举证责任）；《民法典》第545、546条（债权转让与通知，替代原《合同法》79、80条）。

**核心心法**：**先审查债权转让合法性，不要纠结于利率**——纠结利率等于变相承认代偿合法性。尤其关注**是否收到债权转让的有效通知**。

**五步审查**：
1. **核实债权转让通知**：
   - **关键**：债权转让效力，以**是否通知到债务人**为判断依据。
   - **应对**：若受让方（如信托公司）无法证明已向你履行通知义务，该转让**对你不发生效力**，你有权拒绝向受让方还款 → 向法院提出该抗辩，并要求对方提供通知履行证据。
2. **审查原网贷合同合法性**：
   - 即便债权被转让，受让方只享有原债权人的权利；若原合同存在高利贷、违法套贷、暴力催收等非法内容致合同无效，受让方也不能主张债权。
3. **关注诉讼时效**：
   - 民案诉讼时效一般**3年**，自权利人知道/应当知道权利被侵害之日起算。
   - 若已超时效，可据此抗辩拒绝偿还；核对原还款日，判断对方起诉是否超时效。
4. **收集保存证据**：原合同/借款凭证、债权转让通知（如有）、与受让方沟通记录、能证明原合同无效或超时效的证据。
5. **寻求专业法律帮助**：自行应对难度大，建议律师制定策略并代为出庭。

**对方必须提供的材料（依据民诉法67条）**：原始借款合同（**有手印的合同正本**）、债权转让的**书面通知**、准确且完整的**利息收费凭证**。

**应对话术**：
1. 要求提供当初借款的原始合同（必须是有手印的合同正本）。
2. 提供每一次债权转让的书面通知文件、公证送达记录及本人签收记录。
3. 证明所收息费计算方式未超法定红线。

**例外抗辩场景（债权转让常见套路）**：借贷关系被刻意编造、保险/担保关系为虚构搭售、违规电子签名、侵害个人自主选择权与交易权、要求追加放款银行（借款平台）为共同当事人。

- **贷款利息不能抵扣进项税** → 要求**利息收取方开具增值税普通发票**即可（用于成本列支）。

## 五、通用抗辩与谈判武器库（跨场景底座）

### 5.1 格式条款效力瑕疵（攻击"以平台系统记载为准"）
- **场景**：合同中大量"金额/利率/期限**以乙方系统记载为准**"。
- **攻击**：该等条款把金额确定权**单方、排他**授予平台（排除债务人对金额的知情权与异议权），且签合同时未**加粗/弹窗**显著提示 → 依**民法典496条**主张**不成为合同内容**；依**497条**（排除对方主要权利）主张**无效**。
- **论证链**：重大利害关系 → 未提示说明 → 单方确定金额 → 排除知情/异议权 → 不成为合同内容或无效 → 无合同依据的费用（罚息/违约金）应予免除。
- **佐证方法**：比对**平台APP口径 vs 起诉状口径**的金额差异（同一笔债权两套数字），印证"系统说了算"缺乏客观标准。

### 5.2 金额底线：只认本金 / 净占用资金
- **主位（稳妥）**：仅认**剩余本金**（按等额本息公式倒推），罚息、违约金、杂费主张无依据而免除。
- **备位（进攻）**："已还本息全额冲抵本金" → 剩余应还 = **放款总额 − 已还总额**，即"净占用资金"。依据民法典498条（格式条款不利解释）+ 扣款顺序条款约定不明，主张已付款项**优先抵充本金**。
- **谈判阶梯**：开价更低 → 目标（本金一次性结清）→ 可接受（本金+少量补偿）→ 兜底（分 60 期/按 APP 全额）。
- **评估**：进攻立场胜算中等偏低（需突破"先息后本"法定顺序），但**谈判筹码价值极高**，退路稳健。

### 5.3 利率与综合成本红线
- 超出**国家上限**（民间借贷参照4倍LPR，持牌消金受金融监管约束）的部分，超标利息不还。
- 要求逐期核对：罚息是否**按日累计**、是否每还一期同步扣减本金、起算日是否准确、是否漏算"未到期利息"。
- 用 **IRR 测算真实综合资金成本**（含担保费、服务费、保险费等）。合同未披露除利息外的收费的，要求对方举证。

### 5.4 债权转让 / 程序类抗辩
- **债权转让未通知** → 转让不生效（民法典546条）。
- **对方无法提供的三件套**：原始借款合同正本、每次转让书面通知、准确完整的利息收费凭证（民诉法67条）。
- **电子签名无认证** → 合同效力存疑。
- **加速到期未通知** → 起诉时借款未到期，罚息起算日应延后。
- **诉讼时效超期** → 抗辩拒绝履行。

### 5.5 谈判与调解核心话术（可套用）
> "我承认借款事实，已经还了 X 元，占本金 X%，还款意愿明确。但罚息/违约金这块有硬伤：合同把金额确定权单方交给你们系统，签合同时没提示，按《民法典》496条可主张条款不成立、按497条无效。更关键的是，你们自己的 APP 与起诉状金额就差了 X 元，这是'系统说了算'没有客观标准。我的方案：按本金 X 元结清，一次性或分 X 期（每月 X 元，只有原月供的 X%），我能保证按时还。若不接受，我会请法院审查格式条款效力，并向 12378/12363 反映协商被拒。"

## 六、风险红线 & 应避免的坑

1. **绝不缺席**：小额/简易程序被告缺席按"缺席审理"，几乎必然支持对方，丧失抗辩与调解机会；民事一审缺席还可能被公告送达加重责任。
2. **不要盲目提管辖异议**：若法院本来就对你有权（如被告住所地法院），异议必败且浪费程序资源、失去谈调解余地。仅当**异地起诉/对方无连接点**才考虑。
3. **不要纠结单一利率**（尤其债权转让案）：纠结利率等于承认"代偿/受让"合法性，偏离"转让未通知则无效"这个根本点。利率问题退回到"金额拆分审查"处理。
4. **不要与催收对骂/威胁**：既授人以柄，又可能由对方主张你恶意赖账。理性沟通，全程留证。
5. **不要口头答应金额**：一切还款方案须落到**法院调解书/和解协议**书面；口头"分期/减免"不算数。
6. **判决后拖缴代价大**：判决主文通常只有"一次性支付"，且判决后**罚息继续计算**（逐月累加），拖久了金额滚雪球；不履行还会被强制冻结账户、限高、失信名单、可能司法拘留。
7. **调解书要写保护条款**：如"违约时甲方只能就**未清偿余额**申请强制执行，**不得主张已免除的罚息、违约金及利息**"，防止已减免的部分"复活"。
8. **金额永远是主位+备位双轨**：主观偏好（想少还）**绝不覆盖独立法律风险判断**；答辩状保持"稳妥主位 + 进攻备位"两层，以谈判为准、以风险为底线。
